How to connect stores:

Both Coles and Woolworths use cookie import to connect. This avoids bot detection.

  1. Install the Cookie-Editor Chrome extension
  2. Go to coles.com.au or woolworths.com.au and log in
  3. Click the Cookie-Editor icon and click Export (JSON format)
  4. Paste the JSON into the relevant store above and click Import Cookies

Your password is never stored. Only session cookies are saved locally to make API calls.
